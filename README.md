# Placement Management System

## About the Project

The Placement Management System is a Python-based project that analyzes student placement data.

It stores student details such as:
- Student ID
- Student Name
- Branch
- CGPA
- Company
- Package
- Placement Status

## Technologies Used

- Python
- NumPy
- Pandas
- SciPy
- Matplotlib
- Bokeh

## Features

- Displays placement details of students
- Calculates average, highest and lowest CGPA
- Calculates average, highest and lowest package
- Shows placed and not-placed students
- Performs branch-wise placement analysis
- Performs company-wise placement analysis
- Calculates placement percentage
- Performs a SciPy t-test
- Finds correlation between CGPA and package
- Generates Matplotlib graphs
- Generates an interactive Bokeh graph

## Project Results

- Total Students: 10
